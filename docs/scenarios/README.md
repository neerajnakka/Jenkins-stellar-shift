# Failure Scenario Lab

We will add reproducible failure scenarios here.

Each scenario will contain:

- setup
- symptom
- logs
- diagnosis
- root cause
- remediation
- prevention
- interview answer

Example scenarios:

1. Jenkins cannot clone repository
2. Jenkins credential expired
3. npm ci fails
4. unit test fails
5. Sonar quality gate fails
6. Docker build fails
7. registry push denied
8. Kubernetes pod CrashLoopBackOff
9. readiness probe fails
10. deployment rollout hangs
11. ArgoCD reports OutOfSync
12. application returns 500
13. Jenkins agent unavailable
14. build queue grows unexpectedly
